> Этот инструмент может применяться как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит компоненты WinDivert к потенциально опасным или хакерским инструментам, после чего удаляет их и отправляет в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). В Kaspersky, например, есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительнее добавить исключение; если нет, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать неправильно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/FuseBoatwright/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите пункт "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не требуется

4. Извлеките архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Откройте нужный файл
    * Чтобы найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - запуск выбранной стратегии вручную

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб
  - **`Check Status`** - показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - включает или отключает отдельный режим для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После смены значения стратегию необходимо перезапустить.**  
  Текущее состояние отображается в скобках.
  - **`IPSet Filter`** - меняет режим обработки сервисов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret работает, а с ним нет.  
  В скобках отображается текущий режим:
    - `none` - IP-адреса не проверяются
    - `loaded` - адрес проверяется на наличие в списке
    - `any` - под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** - включает или отключает автоматическую проверку обновлений
  - **`Replace active fakes`** - меняет выбранный используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** - загружает актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - запускает ручную проверку обновлений
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность, если приложение внезапно перестало открываться
  - **`Run Tests`** - проверяет стратегии:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/FuseBoatwright/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого Блокнота
  - В новой папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные записи
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантирован. При отсутствии эффекта используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FuseBoatwright/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Обнаружение используемого метода может привести к тому, что ранее рабочая стратегия перестанет помогать.
> В этом репозитории есть много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на базе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов

- Проверьте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/FuseBoatwright/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; устраните ошибки и в конце выберите Y
- Удалите старую папку zapret
- Возьмите свежую версию [со страницы релизов](https://github.com/FuseBoatwright/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", включите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска, используя путь без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если интернет не работает, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Не работает игра/приложение с включённым запретом

- Проверьте в `service.bat`, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Дополнительное обсуждение: [#251](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord
- Проверьте, заработало ли приложение после очистки
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте её
- Если браузер также не подключается, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/FuseBoatwright/tg-ws-proxy)
- Также можно использовать бесплатные MTProto-прокси, найденные в интернете

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит сделать следующее:
- в `service.bat` обновить ipset и активировать `Game Filter`
- если это не помогло, дополнительно включить `ipset any`

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/FuseBoatwright/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда сеть уже добавлена в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
