> ### АНТИВИРУСНОЕ ПО
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик и необходим для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, но сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и попадает в карантин. Название обнаружения обычно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с zapret в исключения антивируса или выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky это параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете, как правильно настроить исключения, предпочтительно добавить исключение. При недостаточном понимании настроек безопаснее отключить детектирование PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в параметрах самой ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый способ.
    * На роутерах Keenetic включите опцию "Транзит запросов". При выключенной настройке Secure DNS на компьютере может работать неправильно.

2. Откройте [страницу последнего релиза](https://github.com/FuseBoatwright/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar.

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить запуск вместе с системой, перейдите в **`service.bat`**: `Install Service` -> *выберите подходящую стратегию*.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты — ALT, FAKE и другие, пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) объединяет установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить из служб стратегию и WinDivert.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — переключить обход для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние — включено или выключено — указано в скобках.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Опция особенно полезна при проверке ресурса, который без zapret доступен, а с ним не работает.  
  В скобках отображается текущий режим:
    - `none` — ни один IP не проверяется;
    - `loaded` — IP проверяются на наличие в списке;
    - `any` — фильтр применяется к любому IP.
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и соединения с голосовым чатом Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** — проверить стратегии:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно заметить на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/FuseBoatwright/zapret-discord-youtube/issues/522).

### Не удалось подобрать ни одну стратегию
- Откройте командную строку с правами администратора.
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Веб-версия Telegram не подключается

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - скопируйте весь текст из открывшегося блокнота;
  - от имени администратора откройте текстовым редактором файл `hosts` в созданной папке;
  - вставьте скопированный текст в конец файла (либо замените ранее добавленный аналогичный блок);
  - сохраните файл и проверьте соединение ещё раз. Если результат прежний, убедитесь, что hosts действительно был сохранён.

#### Результат не гарантируется. При отсутствии эффекта используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/FuseBoatwright/tg-ws-proxy) или одним из публичных прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегия может со временем утратить работоспособность.**
> Обнаружение используемой стратегии способно произойти не сразу: некоторое время она работает, а затем перестаёт.
> Здесь доступно много стратегий обхода. Если готовые варианты не помогают, создайте новую на основе одной из них и измените параметры. Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки.

- Убедитесь, что нужный адрес добавлен в доменные или IP-списки.

- Проверьте другие варианты, в том числе **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/FuseBoatwright/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление
- Сначала сохраните добавленные вами ресурсы и другие данные.
- Перезапустите компьютер.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце ответьте Y.
- Удалите старую папку zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/FuseBoatwright/zapret-discord-youtube/releases) — архив `zapret-discord-youtube-...`.
- Щёлкните по архиву правой кнопкой, откройте свойства. Если внизу справа есть пункт разблокировки, установите его, нажмите "Применить" и затем "ОК".
- Распакуйте файлы в новую папку в корне диска, избегая пробелов и специальных символов.
- Запускайте разные скрипты `general`, проверяя доступ к интернет-ресурсам. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на доступ к неожиданным ресурсам.

### Античит обнаруживает WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. В командной строке Windows узнайте имя службы (Win+R, затем `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Для начала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработал ли клиент Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не работает даже в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/FuseBoatwright/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Игры не работают

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно помогает такой порядок:
- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно активируйте `ipset any`.

Учитывайте, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/FuseBoatwright/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на вашу проблему нет

- Опишите её [здесь](https://github.com/FuseBoatwright/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Расширить список адресов для обхода можно с помощью следующих файлов:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP сети присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
